# Framework Selector — Reference

Use this to choose the right framework for the question. Start with the decision, not the framework.

---

## Decision Tree

**What type of strategic question is this?**

### "Is this market/industry attractive for us?"
→ **Porter's Five Forces** — assess industry profitability potential
→ **PESTLE** — broader macro forces (add if regulatory/tech forces are significant)
→ Combine with internal capability assessment to close the gap

### "Can we win in this market?"
→ **VRIO** (Value, Rarity, Imitability, Organization) — do our resources create sustainable advantage?
→ **Value Chain Analysis** — where do we create value, where are we weaker?
→ Often best done as a structured comparison against the leading competitor

### "How should we grow?"
→ **Ansoff Matrix** — four growth vectors; forces a strategic choice
→ **BCG Matrix** — if multi-business, understand portfolio position first
→ For organic vs. inorganic: **Market Entry Modes** or **M&A Evaluation**

### "Why are we losing market share / customers?"
→ **Value Chain Analysis** — where in the chain is the problem?
→ **Competitive Positioning** — what are competitors doing differently?
→ Often requires primary research (customer interviews) more than frameworks

### "Should we acquire Company Z?"
→ **M&A Evaluation Framework** — strategic rationale, target quality, deal economics
→ **Porter / VRIO** for strategic fit assessment
→ Due diligence frameworks for target assessment

### "How do we design the organization for the future?"
→ **Target Operating Model (TOM)** — integrated view: processes, technology, governance, people
→ **McKinsey 7S** — for alignment assessment (structure, strategy, systems, staff, skills, style, shared values)

### "Is there a different way to compete (not just better)?"
→ **Blue Ocean / Value Innovation** — which factors to eliminate/reduce/raise/create?
→ **Platform / Network Effects** — if the business model involves multi-sided markets

### "What macro forces should we plan for?"
→ **PESTLE** — political, economic, social, technological, legal, environmental
→ Use for scenario planning inputs, not as standalone strategy

## Framework Anti-Patterns

When NOT to use a framework:
- **SWOT for serious strategy work** — SWOT is useful for initial brainstorming, but its 2x2 format encourages lists over analysis. It doesn't force prioritization or strategic logic. Almost never the right tool for a consulting deliverable.
- **Porter when the industry is nascent** — Five Forces assumes a defined industry structure. For emerging markets, the structure is still forming — Porter becomes speculative.
- **BCG when you only have one business unit** — The matrix requires a portfolio context to be meaningful.
- **7S when the question is external** — 7S is purely internal. Don't use it to assess market dynamics.

See `references/anti-patterns.md` for extended list.
