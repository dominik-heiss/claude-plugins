# Slide Craft — Reference

Rules for consulting-grade slides. Every rule has a reason.

---

## Action Title Rules

**One message per title.** The title delivers the insight; the slide proves it.

Formulation: [Subject] [verb] [specific claim]
- "European EV charging market grows at 8% CAGR through 2030" ✅
- "Three structural shifts are redefining competitive dynamics" ✅
- "Acquisition of Target Z creates EUR 45M of NPV value" ✅

Test: Read only the titles of all slides in sequence. Do they form a coherent argument? If yes, the storyline is working.

---

## One Message Per Slide

If a slide has two messages, split it into two slides. Forcing a reader to hold two ideas simultaneously reduces comprehension and weakens both messages.

Signs a slide has too many messages:
- Title has "and" in it: "Market is large and growing competition is intensifying"
- Slide has two charts with different conclusions
- Bullets contradict each other

---

## Visualization Hierarchy

Choose the simplest representation that conveys the insight:

1. **Single number / callout** — for one key metric (strongest emphasis)
2. **Simple chart** — for trend, comparison, or distribution
3. **Table** — for structured comparison of multiple dimensions
4. **Bullets** — for unquantified points that need listing
5. **Text paragraph** — almost never in main deck; maybe in executive summary

**Chart selection:**
- Trend over time → line chart
- Comparison between items → bar chart (horizontal for long labels)
- Part-to-whole → waterfall (for bridges), pie only if ≤3 segments
- Correlation → scatter plot
- Hierarchy → tree diagram
- Geographic → map

Avoid: 3D charts, dual-axis charts (almost always misleading), pie charts with >5 segments.

## Slide Anatomy

**Standard consulting slide structure:**
```
┌─────────────────────────────────────────────────┐
│ ACTION TITLE — the key takeaway                 │
│ SUB TITLE — summary or description if needed    │
├─────────────────────────────────────────────────┤
│                                                 │
│              EVIDENCE                           │
│    (chart / table / bullets)                    │
│                                                 │
├─────────────────────────────────────────────────┤
│ Footnote / caveat                               │
│ Source                                          │
└─────────────────────────────────────────────────┘
```

Every slide has a source. No unsourced data in a consulting deliverable.

## Bullet Point Rules

- Maximum 5 bullets per text box 
- Each bullet: maximum 2 lines
- Bullets are parallel (all start with same grammatical structure: all nouns, all verbs, all clauses)
- Bullets support the action title — they don't introduce new ideas

If you find yourself writing 7 bullets, you have:
- Two slides, or
- A table that organizes the information more efficiently, or
- Analysis that isn't sharp enough yet

## Appendix

The appendix is not a dumping ground — it's a structured library.

**What goes in the appendix:**
- Detailed methodology (market sizing assumptions, model assumptions)
- Full data tables referenced in main deck charts
- Sensitivity analyses
- Background on competitors, markets, frameworks used
- Interview notes / source summaries

**Appendix slide format:** Same action title rule applies. "Source A says EUR 30B, Source B says EUR 45B — we use EUR 38B" is a valid appendix title.

**Numbering:** Appendix slides are labeled A1, A2, A3, etc. Main deck slides use continuous numbering.

## Common Slide Mistakes

**"Background" sections:** Clients usually know their own history. Skip to the issue. If context is needed, one slide maximum.

**All-bullet slides with no synthesis:** Lists of facts without a "so what" action title. Forces the reader to synthesize — that's the consultant's job.

**Charts without labeled takeaways:** A chart without a callout or annotation pointing to the key insight requires the reader to find it. Add an arrow, a callout box, or a highlighted data point.

**Inconsistent terminology:** "Revenue," "Sales," and "Turnover" used interchangeably. Pick one term per concept and use it throughout.

**Slides that require verbal explanation to make sense:** If you have to explain a slide verbally to make it work in a meeting, fix the slide.
