# Pyramid Principle — Reference

Barbara Minto's framework for structuring executive communication. Core mechanics.

---

## The Fundamental Rule

**Answer first. Reasoning second. Evidence third.**

This is counterintuitive for analysts who have spent weeks building up to a conclusion. The pyramid principle inverts the typical analytical thought process for communication purposes.

Why: Executives make decisions. To evaluate a recommendation, they need the answer first so they can decide how much scrutiny to apply. If the recommendation is obvious, they don't need the full argument. If it's contentious, they'll want to see the reasoning.

---

## Deductive vs. Inductive Groupings

**Deductive grouping** (logical chain):
- Statement A is true
- Statement B follows from A
- Therefore, Statement C

Use when the audience needs to follow the logic step-by-step to accept the conclusion.

**Inductive grouping** (parallel supporting points):
- Point 1 supports the conclusion
- Point 2 supports the conclusion
- Point 3 supports the conclusion
- Therefore, conclusion

Use for most consulting deliverables. Faster to read; easier to restructure.

Most slide decks use inductive grouping at the key line level (3 parallel reasons support the governing thought) and deductive reasoning within individual sections.

---

## The MECE Requirement for Storylines

The key line items must be:
- **Mutually exclusive:** Each reason supports the governing thought from a different angle
- **Collectively exhaustive:** Together, they make the case completely

**Test:** If all key line items were true, would the governing thought be proven? If not, a key line item is missing.

**Numbering test:** If you can't say "for these 3 reasons," the key line items aren't at the same level of abstraction or aren't truly parallel.

---

## Governing Thought Formulation

A governing thought must:
1. Answer the core question (what decision, what recommendation)
2. Be specific (not "Company X should grow" but "Company X should acquire Target Z for EUR 120-150M")
3. Be defensible (it's the output of the analysis, not a platitude)
4. Fit in one sentence

**Weak governing thoughts:**
- "The market presents significant opportunities for Company X" — too vague
- "Company X faces both opportunities and challenges" — says nothing
- "We recommend a phased approach to market entry" — not specific enough

**Strong governing thoughts:**
- "Company X should enter the European EV charging market via acquisition of Target Z, targeting 15% market share by 2028"
- "Company X's cost structure is 30% above best-in-class; a focused operational transformation can close 70% of the gap within 18 months"

---

## Common Pyramid Errors

**Missing governing thought:** The deck has key line items but no unified message. Audience must infer the recommendation.

**Key line items that don't support the same conclusion:** "Reason 1 supports Recommendation A, Reason 2 supports Recommendation B." Structural incoherence — the storyline needs restructuring.

**Evidence at the wrong level:** Detailed methodology and data tables in the main deck instead of the appendix. Buries the argument.

**Circular reasoning:** The governing thought is restated as a supporting argument. "We should enter the market because the market is attractive" — why is it attractive? That's the argument.

**Premature detail:** Explaining HOW to implement before convincing WHY to act. First make the case, then address execution.

---

## Iterating the Storyline

Storylines often need multiple revisions. Signs it needs more work:
- You can't write the governing thought in one sentence without conjunctions ("and", "but", "also")
- The key line items overlap or don't support the same conclusion
- You're unsure which section a slide belongs in
- The deck's recommended action changes between slide 3 and slide 10

When to restructure: whenever analysis findings change the conclusion. Don't "fit" new findings into an old storyline — update the storyline.
